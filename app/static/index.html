Modele AI

Stan konfiguracji obecnych dostawców. Wizard dodawania kluczy i wykrywania modeli jest następnym etapem.

Konfiguracja kluczy nadal odbywa się po stronie serwera. Ten panel nie prosi o przesyłanie sekretów do pamięci przeglądarki.

Knowledge Studio

Przyszłe źródła RAG: dokumenty, notatki, pliki Markdown, PDF oraz repozytoria. Zatwierdzanie faktów jest już dostępne w Pamięci projektu.

Import dokumentów

Plan: upload → ekstrakcja → podział na fragmenty → FTS5 i embeddingi → Retrieval Inspector.

Import plików nie jest jeszcze aktywny. Nie przechowujemy plików bez zakończonego procesu indeksowania i kontroli źródeł.

Observability

Podstawowe liczniki zapisanej aktywności. Czasy odpowiedzi, tokeny i koszty będą wymagały osobnego instrumentowania.

Stan monitoringu

Widok pokazuje rzeczywiste liczniki SQLite, bez wymyślonych statystyk. Kolejny etap: śledzenie przebiegu żądań, błędów dostawców, czasu retrievalu i kosztów.

Ustawienia

Personalizacja interfejsu zapisywana lokalnie w tej przeglądarce. Hasło i klucze API nie są zapisywane w localStorage.

Tryb prywatności

„Tylko lokalnie” blokuje użycie modeli chmurowych w formularzu rozmowy. Administracyjna flaga FORCE_LOCAL_ONLY po stronie serwera zapewnia dodatkowe wymuszenie.
